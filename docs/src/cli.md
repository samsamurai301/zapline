# Project layout & the CLI

The `zapline` command-line tool scaffolds projects (`zapline new`, with minimal, api and full templates), generates code, runs a reloading development server (`zapline dev`), prints the route table (`zapline routes`), exports the OpenAPI document (`zapline openapi`), checks your environment (`zapline doctor`) and runs benchmarks (`zapline bench`). This page will cover installing it, the layout of a generated project, each command with its options, and how the CLI cooperates with the framework through `ZAPLINE_PRINT_ROUTES` and `ZAPLINE_EXPORT_OPENAPI`.
